Бір беттік шақыру сайты (static HTML, GitHub Pages).

## 1. Что менять перед публикацией

Все данные — в одном месте: открой `index.html`, найди блок `const CONFIG = {`
(в самом низу файла, внутри `<script>`). Меняй только значения в кавычках.

```js
const CONFIG = {
  eventDate: "2026-11-15T18:00:00+05:00",   // дата и время тоя
  dateKz:    "15 қараша, сағат 18:00",      // как видит гость
  venue:     "«NNN» мейрамханасы",          // название мейрамханы
  audioFile: "music.mp3"                    // файл музыки
};
```

**`eventDate`** — формат строгий: `ГОД-МЕСЯЦ-ДЕНЬ` + `T` + `ЧАС:МИНУТА:00+05:00`.
`+05:00` — часовой пояс Казахстана, **не убирай**: без него таймер покажет
неправильное время гостю, у которого на телефоне другой часовой пояс.

Пример: той 15 ноября 2026 в 18:00 → `"2026-11-15T18:00:00+05:00"`

**`dateKz`** — это просто текст на экране, пиши как хочешь видеть:
`"15 қараша, сағат 18:00"`.

## 2. Музыка

Положи mp3 рядом с `index.html` и назови `music.mp3`.

- файл есть → в правом нижнем углу появится круглая кнопка ♪
- файла нет → кнопка не появится, ошибок у гостя не будет
- автозапуска нет специально: браузеры его всё равно блокируют, музыка играет по тапу

## 3. Публикация на GitHub Pages

### Шаг 1. Создать репозиторий

github.com → **New repository**:
- Repository name: `rafael-45` (или любое другое)
- Видимость: **Public** — на бесплатном плане Pages работает только так
- README, .gitignore, лицензию **не добавлять**
- **Create repository**

### Шаг 2. Запушить

В папке проекта (PowerShell):

```powershell
git remote add origin https://github.com/ВАШ_НИК/rafael-45.git
git push -u origin main
```

### Шаг 3. Включить Pages

Репозиторий → **Settings** → слева **Pages**:
- Source: **Deploy from a branch**
- Branch: `main`, папка `/ (root)`
- **Save**

Через 1–2 минуты сайт живой:

```
https://ВАШ_НИК.github.io/rafael-45/
```

Эту ссылку и рассылай гостям.

### Обновить сайт потом

```powershell
git add .
git commit -m "дату поправил"
git push
```

Через минуту изменения на сайте. Если старая версия висит —
обнови страницу с очисткой кэша (Ctrl+F5).

## 4. Посмотреть локально до публикации

```powershell
python -m http.server 8000
```

Открыть `http://localhost:8000`. Остановить — Ctrl+C.

Просто двойным щелчком по `index.html` тоже откроется, но музыка
через `file://` в части браузеров не заиграет — поэтому лучше через сервер.
